# Quick 261109-i10: walk git history once per insert call

`insertConfigFiles` walks history once for all requested paths and builds a
path-to-last-commit map. `GatherMetadata` reads the map first and falls back to
the unchanged per-file walk on a miss. The map is cleared when the call returns.
