  <action>
    Per D-01 and D-02, create `utils/tls.go` with:

    1. A `TLSFiles` struct with six string fields: `CertFile`, `CertText`, `KeyFile`, `KeyText`, `CAFile`, `CAText`. This is a simple, package-agnostic struct (not tied to agent proto types) per the research recommendation.

    2. A `BuildTLSConfig(f TLSFiles) (*tls.Config, error)` function that:
       - Returns `(nil, nil)` when neither cert nor key is provided (no TLS)
       - Returns error if only one of cert/key is set: `fmt.Errorf("tls: cert and key must both be set")`
       - Reads cert from `CertFile` (via `os.ReadFile`) or uses `CertText` directly
       - Reads key from `KeyFile` (via `os.ReadFile`) or uses `KeyText` directly
       - Calls `tls.X509KeyPair(certPEM, keyPEM)` to parse the pair
       - If CAFile or CAText is provided, reads CA PEM, creates `x509.NewCertPool()`, calls `pool.AppendCertsFromPEM(caPEM)`, checks the bool return, sets `tlsCfg.ClientCAs = pool` and `tlsCfg.ClientAuth = tls.RequireAndVerifyClientCert`
       - Returns the `*tls.Config`

    3. Create `utils/tls_test.go` with a test helper `generateSelfSignedCert(t *testing.T) (certPEM, keyPEM []byte)` that generates a self-signed ECDSA P-256 cert for 127.0.0.1 valid for 1 hour. Use `t.TempDir()` to write cert/key files for file-based tests. Use `crypto/x509`, `crypto/ecdsa`, `crypto/elliptic`, `crypto/rand`, `encoding/pem`, `math/big`.

    4. Write tests covering all behaviors listed above using table-driven tests with `testify/assert` and `testify/require`.

    Imports needed in tls.go: `crypto/tls`, `crypto/x509`, `fmt`, `os`.
    Imports needed in tls_test.go: `crypto/ecdsa`, `crypto/elliptic`, `crypto/rand`, `crypto/x509`, `crypto/x509/pkix`, `encoding/pem`, `math/big`, `net`, `os`, `path/filepath`, `testing`, `time`, `github.com/stretchr/testify/assert`, `github.com/stretchr/testify/require`.

    Do NOT set `InsecureSkipVerify` anywhere. Do NOT use `tls.LoadX509KeyPair` directly — use `tls.X509KeyPair` with bytes (since we support both file and text input).
