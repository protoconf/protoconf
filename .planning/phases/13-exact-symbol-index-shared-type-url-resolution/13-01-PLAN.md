## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `src/` tree -> scan tier | `.proto` file *contents* under the project's own `src/` are read as bytes and regex-matched by the new scan. Project-controlled, not network input, but newly read by a code path that did not read them before. |
| scan candidate path -> `ParseOne` | A path produced by the scan crosses into `ParseOne`, which opens a file. This is the one place the scan can cause an arbitrary file open. |
